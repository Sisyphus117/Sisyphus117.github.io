问题来源于Hands on Machine Learning第二版

题目和解答

  1. Is it okay to initialize all the weights to the same value as long as that value is selected randomly using He initialization?
    1. 不可以,He初始化必须满足其一:
      1. 权重 W 从均值为 0，方差为 的正态分布中随机抽取。
      2. 权重 W 在 [−r, +r] 之间随机抽取，其中 。
    2. 因为相同初始值的权重会导致对称陷阱,同一层的神经元更新方式完全一样
  2. Is it okay to initialize the bias terms to 0?
    1. 可以
  3. Name three advantages of the SELU activation function over ReLU.
    1. SELU的输出是自归一化的,能够解决梯度爆炸/消失
    2. 由于SELU在z<0处是非零值,可以避免神经元死亡
    3. 收敛速度更快
  4. In which cases would you want to use each of the following activation functions: SELU, leaky ReLU (and its variants), ReLU, tanh, logistic, and softmax?
    1. SELU的效果总的来说更好,但需要满足所有的层都是全连接的
    2. leaky ReLU计算速度快,适用于延迟敏感的问题
    3. ReLU的计算速度最快,适用于卷积神经网络场景
    4. Tanh均值为0且对称
    5. logistic/sigmoid适用于二分类问题
    6. softmax适用于在输出层之前,把概率之和缩放到1
  5. What may happen if you set the momentum hyperparameter too close to 1 (e.g., 0.99999) when using an SGD optimizer?
    1. 梯度下降方向很大程度上由上一次下降方向决定而不是当前step的梯度
    2. 使得数据有很大的惯性,很有可能冲过最优解
  6. Name three ways you can produce a sparse model.
    1. 使用L1正则化
    2. 在训练结束后手动把较小的参数设置为0
    3. 使用SELU等激活函数
  7. Does dropout slow down training? Does it slow down inference (i.e., making predictions on new instances)? What are about MC dropout?
    1. dropout会减慢训练速度,因为需要缩放输出值,以及决定哪些神经元被丢弃,训练轮数也会响应增加;推理速度不会影响
    2. MC会减慢推理速度,训练过程同理;在推理中,会开启不同神经元对同一输入多次预测,产生多个结果,因此推理速度更慢
